# Univerus order exchange agent skill

Публичный скилл для чтения биржи заказов Универус из любого агента, который умеет запускать локальные команды. Отдельный сервер или MCP (протокол подключения инструментов к агенту) не нужен: скрипт обращается напрямую к API (интерфейсу программного доступа) Универус.

**Статус:** API и раздел «Подключения» готовятся в основном репозитории Универус. Скилл заработает после их выпуска на сайт.

## Подключение

1. Войдите на [univerus.ai/marketplace](https://univerus.ai/marketplace), откройте «Подключения» и создайте ключ с правом чтения.
2. Сохраните ключ в переменной окружения `UNIVERUS_API_KEY` на своём компьютере или в хранилище секретов агента. Не добавляйте его в репозиторий и не отправляйте в чат.
3. Установите папку `skills/univerus-marketplace` как скилл вашего агента. Для Codex скопируйте её в `~/.codex/skills/`, для Claude Code — в `~/.claude/skills/`.

Примеры команд из папки скилла:

```bash
python3 scripts/marketplace.py categories
python3 scripts/marketplace.py orders --today --timezone Europe/Moscow --sort newest
python3 scripts/marketplace.py orders --from-at 2026-09-01T00:00:00+03:00 --before-at 2026-09-08T00:00:00+03:00
python3 scripts/marketplace.py order <order-id>
```

`--date-field message` выбирает дату исходного сообщения (по умолчанию), а `--date-field discovered` — дату добавления заказа в Универус. Начало периода включается, конец не включается. Список выдаётся страницами; для следующей используйте `--page 2`.

Ключ даёт доступ только к опубликованным объявлениям и активным категориям. У него нет срока действия: в кабинете его можно временно выключить, снова включить или удалить. Доступ по ключу также прекращается, если заканчивается доступ к бирже.
