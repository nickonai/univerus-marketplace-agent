# Помощник по заказам и вакансиям Универус

Один скилл для подбора объявлений под навыки человека, разбора требований, подготовки честных откликов и улучшения резюме, профиля и портфолио. Подходит новичкам: начинает с нескольких уместных вопросов, использует уже известный профиль. Биржа только читается; готовый отклик отправляет сам пользователь.

## ChatGPT и совместимые MCP-клиенты: вход через OAuth

Python и персональный ключ для этого пути не нужны.

1. Войдите в Универус и откройте **Настройки → API и агенты** (`/settings?tab=api-agents`). Нужен действующий доступ к бирже.
2. В ChatGPT откройте [Plugins](https://chatgpt.com/plugins), нажмите **+ → Add custom MCP server** (если доступно вашему аккаунту/рабочему пространству). Введите название «Биржа Универус» и URL `https://univerus.ai/api/mcp/marketplace`, выберите OAuth, просмотрите предупреждение и создайте подключение. В другом MCP-клиенте добавьте удалённый Streamable HTTP сервер с тем же URL и OAuth. Клиенту нужны discovery, DCR и PKCE S256.
3. В открывшемся окне Универус войдите в свой аккаунт и разрешите чтение биржи. Не вставляйте пароли, ключи и токены в чат.
4. Включите полученный плагин в новой беседе (в ChatGPT — выберите через `@`). Попросите проверить доступ и категории. Должны обнаруживаться `account_access`, `marketplace_categories`, `marketplace_orders`, `marketplace_order`.
5. Скопируйте инструкцию из [CHAT-PROMPT.md](CHAT-PROMPT.md) в беседу. Для полного поведения можно приложить `skills/univerus-marketplace/SKILL.md` и `references/connection.md` как читаемые файлы и попросить следовать им. Если среда не умеет читать файлы, вставьте их текст. Это инструкция для беседы, а не автоматическая установка скилла.

Пример первого запроса: «Помоги подобрать заказы. Я начинающий дизайнер, делал учебные карточки товаров, могу работать 10 часов в неделю. Начни с пары уточнений». Если профиль уже известен: «Найди подходящие объявления за неделю, выбери три и объясни пробелы».

Для ChatGPT используйте MCP-подключение и инструкцию из шага 5. Добавление собственного MCP должно быть разрешено настройками аккаунта и рабочего пространства. MCP предоставляет инструменты биржи; инструкции помощника передаются в беседу отдельно.

Подробнее о подключении собственного MCP — в [официальной документации OpenAI](https://developers.openai.com/apps-sdk/deploy/connect-chatgpt).

## Агент с HTTP или локальными командами: персональный API-ключ

1. В Универус в **Настройки → API и агенты** создайте ключ с областью `marketplace:read`. Секрет `uvp_` показывается один раз. Храните его в защищённых настройках агента либо переменной окружения `UNIVERUS_API_KEY`; не в чате, аргументах команды или репозитории.
2. Получите репозиторий и установите папку `skills/univerus-marketplace` штатным способом своего агента. Для Codex локальная папка скилла — `~/.codex/skills/univerus-marketplace`; не перезаписывайте уже установленную версию без проверки. Если хост не поддерживает скиллы, передайте ему SKILL.md и справку как инструкции и обеспечьте HTTP-исполнение.
3. Нужен Python 3.10+ с базой часовых поясов, внешних библиотек нет. Выполните из папки скилла:

```bash
python3 scripts/marketplace.py access
python3 scripts/marketplace.py categories
python3 scripts/marketplace.py orders --today --timezone Europe/Belgrade --sort newest
python3 scripts/marketplace.py orders --from-at 2026-10-01T00:00:00+02:00 --before-at 2026-10-08T00:00:00+02:00 --date-field discovered
python3 scripts/marketplace.py orders --search 'дизайн' --page 2 --per-page 20
python3 scripts/marketplace.py order <order-uuid>
```

Дата начала включается, конца — нет. Указывайте свой часовой пояс для `--today` (сохранённый default скрипта — Europe/Moscow). `message` — дата сообщения, `discovered` — первое сохранение в бирже. Списки постраничные, default 20, максимум 100; метаданные ответа показывают охват. Скрипт не запускает поиск автоматически по расписанию и не хранит историю показов.

Для агента без Python доступны GET `/api/v1/account/access` и `/api/v1/marketplace/{categories,orders,orders/<uuid>}` с `Authorization: Bearer <key>`. Точные поля, MCP-примеры и ошибки — в [справке](skills/univerus-marketplace/references/connection.md). Общий MCP `/api/mcp` поддерживает персональный ключ в безопасно настроенном заголовке Authorization.

Срок ключа необязательный; его можно приостановить, включить и отозвать. Старые ключи `uvm_` не принимаются. Доступ зависит от текущих прав аккаунта и продукта. OAuth-подключение также можно отозвать в настройках; по текущему контракту повторная авторизация нужна по истечении 30 дней. Для остановки регулярного поиска отдельно отключите задачу в планировщике своего хоста.

## Возможности и границы

- Подбор учитывает навыки, опыт, портфолио, бюджет, время и ограничения. Отсутствующие факты уточняются постепенно.
- Заказ и вакансия разбираются по-разному. Перед откликом читается полный текст; неизвестные условия и пробелы называются прямо.
- Нет подходящих объявлений — допустимый результат. Не обещаются заработок, ответ автора, полнота внешних источников или отправка отклика.
- Ежечасный поиск возможен только при поддержке расписания, состояния и уведомлений конкретным хостом. Подключение MCP само этого не даёт. Реальное расписание здесь не создаётся.

Публичная документация платформы: [быстрый старт](https://univerus.ai/docs/api/quickstart.md), [инструкция API](https://univerus.ai/docs/api/skill.md), [OpenAPI](https://univerus.ai/api/v1/openapi.json). Параметры подключения и примеры запросов приведены в справке.
